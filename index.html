Agentic AI projects

Three LLM agents that turn a plain-language engineering question into code that runs, checks itself and returns results. Each diagram is redrawn from the project's actual LangGraph workflow.

ChemSimGuide

Global Top 20 of 6,000+ teams, Google GenAI Intensive Course Capstone 2025

A conversational assistant for setting up chemical simulations in Cantera, the open-source library for kinetics, thermodynamics and transport. Engineers describe what they want to simulate; the agent breaks the setup into steps, explains each one and writes the Cantera code.

A LangGraph agent routes between a documentation search over Cantera's docs (RAG with ChromaDB), a literature search and a code generator, using Google's Gemini models.

Gemini API, LangGraph, RAG, ChromaDB, Cantera, Python

ODE Forge

LLM Hackathon for Materials Science and Chemistry

An agent that takes a researcher from a conversation about a dynamic system to a running ODE simulation and an interactive analysis dashboard, such as phase-space portraits and oscillation periods.

Users can upload their own papers, which the agent searches first (RAG). The agent then writes the simulation script in stages and runs it in a Docker sandbox. If the code fails, a debugger node reads the error, fixes the code and runs it again.

OpenAI GPT-4o, LangGraph, LangChain, Streamlit, Docker, SciPy, SymPy

Agentic Wastewater Epidemiology System

Mitacs-funded. II Prize for oral presentation, IIChE CHEMCON 2025

An agent for wastewater-based epidemiology. It researches the literature and a local library of papers, agrees an SEIR model specification with the user, then generates a script that fits the model's parameters to real wastewater surveillance data by least squares.

The code runs in a Docker sandbox with the same self-correcting debug loop. The repository has two versions: an SEIR model chatbot and an SEIR inverse model that estimates parameters from data.

Presented as "An LLM-Driven Framework for Research, Hypothesis Generation, and Simulation of Sewer Epidemiology Models," with Salil Mathew, Tianlong Liu, Madhumita Ray and Domenico Santoro.

OpenAI API, LangGraph, RAG, ChromaDB, Docker, SciPy (solve_ivp, least_squares)

Research

My PhD asked how to make machine learning dependable for refinery processes, where plant data is noisy and models need to respect chemistry. Much of the work builds physical knowledge into the model and measures what that adds; the rest pairs data-driven models with uncertainty estimates and optimisation.

Neural ODEs for reaction kinetics

Neural ordinary differential equations that learn hydrocracking kinetics from data. Adding Arrhenius kinetics and other physical constraints cut prediction error by 40 to 55% and gave interpretable kinetic parameters.

Hybrid models of industrial units

A modular neural network that mirrors the structure of an industrial hydrocracking unit, predicting product yields with 23.5% lower error than standard ML baselines and supporting operating optimisation.

Surrogates with uncertainty

A multi-output Gaussian Process surrogate of an industrial hydrotreater trained on six years of plant data, used for multi-objective optimisation of operating conditions with uncertainty estimates.

Spectra to properties

One-dimensional CNNs that predict crude oil properties from FTIR spectra. For viscosity, RMSE fell from about 160 to around 60 compared with PLS, PCR and PLS-GA on the same data.
